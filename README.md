# Chenglin Liu Academic Homepage

这是根据 `LIU-cv0906.doc` 制作的英文个人学术主页第一版。页面正文为英文，About 中的 abstract 同时提供英文与中文。

## 直接预览

双击 `index.html` 即可打开。为获得与部署后最接近的效果，也可以在此文件夹启动任意静态文件服务器，例如：

```powershell
python -m http.server 8765
```

然后使用以下两个入口：

- 公开只读预览：`http://127.0.0.1:8765/`
- 本机所有者编辑入口：`http://127.0.0.1:8765/?edit=1`

正常网址不显示编辑按钮。`?edit=1` 只打开浏览器本地编辑器；即使其他人知道这个参数，他们的改动也只会进入他们自己的浏览器，不能修改服务器或你发布的网站文件。真正的账号鉴权和在线写回需要额外后端，当前静态版不包含该能力。

## 页面内编辑

1. 打开带有 `?edit=1` 的所有者编辑入口，点击右上角 **Edit page**。
2. 点击黄色虚线标记的文字并直接修改。
3. 点击 **Edit links** 修改 Google Scholar、LinkedIn、ResearchGate、GitHub、导师和论文链接。
4. 点击 **Content manager** 管理论文、研究方向、教育、工作经历、学术服务和个人活动。每类内容均可新增、编辑、删除、上下排序和显示或隐藏。
5. 点击每个可删除内容块右上角的红色 `×` 可快速隐藏该项；使用 **Manage blocks** 可批量恢复或继续隐藏条目。
6. 点击 **Save locally**，文字、链接、列表内容、排序和隐藏状态会保存在当前浏览器的 `localStorage` 中。
7. 使用 **Export JSON** 备份，或使用 **Import JSON** 在另一个浏览器中恢复。
8. **Reset** 会恢复这份网站随附的 CV 基准内容。

浏览器本地保存不会改写 `index.html`，清理浏览器数据后也可能丢失，因此重要修改请导出 JSON。若后续需要让在线访客共同编辑或跨设备同步，需要另行增加带身份验证的后端。

## 内容与链接边界

- 个人主页、导师主页和三条论文/项目链接直接来自简历中的内嵌超链接。
- 六篇已发表论文使用经过题名匹配的 DOI 链接。
- CV 未提供公开链接的稿件没有附加链接，也没有用同名搜索结果代替。
- 本版本仅在本地创建，尚未注册域名、部署、上传或发布。

## GitHub Pages 地址

网站通过 GitHub Pages 公开发布于：

`https://chenglinchris.github.io/`

GitHub Pages 的访客只能读取静态文件，不能修改仓库内容。若要把浏览器本地编辑结果变成所有访客都能看到的版本，需要导出 JSON 后更新网站源文件并重新发布；你可以把导出文件交给 Codex 处理，而不必手工改代码。

## 文件

- `index.html`：页面结构和 CV 基准内容
- `styles.css`：响应式视觉样式
- `app.js`：编辑、保存、导入导出、链接编辑、筛选和移动导航
- `assets/`：从用户原图生成的网页优化 WebP 派生文件
- `assets/LIU_Chenglin.pdf`：供访客下载的 PDF 简历副本，源简历保持不变
- `tests/site.spec.cjs`：Playwright 自动化验收

测试、预览、临时文件以及不再使用的旧 Word 简历通过 `.gitignore` 保留在本地，不进入公开仓库。
